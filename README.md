# Dysco

Dysco is a command-line tool to help you understand where your disk space is being used. It scans directories and provides a visual representation of disk usage.

## Features

- Scans directories to show disk usage
- Provides a visual representation of disk usage
- Supports multiple threads for faster scanning
- Handles window resizing events
- Allows for deletion of files with confirmation
